# tg-gif-bot

Бот для Telegram: кидаешь картинку, GIF, видео, стикер или ссылку, а он отвечает гифкой, которую можно сохранить в «Мои GIF».

## 1. Создать бота
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя.
2. Скопируй токен вида `123456:ABC...`.

## 2. Проверить у себя (необязательно)
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
BOT_TOKEN=твой_токен .venv/bin/python bot.py
```
Без `WEBHOOK_URL` бот работает в режиме polling, публичный адрес не нужен.

## 3. Залить на Render (бесплатно)
1. Загрузи эту папку в новый репозиторий на GitHub (можно приватный).
2. На [render.com](https://render.com) → **New → Blueprint** → выбери репозиторий. Render подхватит `render.yaml`.
3. Когда спросит `BOT_TOKEN`, вставь токен → **Apply**.

Адрес для webhook бот берёт сам из `RENDER_EXTERNAL_URL`.

**Особенность бесплатного плана:** после ~15 минут без сообщений сервис засыпает. Первое сообщение его будит, ответ на него может идти до минуты. Дальше бот отвечает сразу.

## 4. Инциденты (/inc)
Пользователь пишет боту `/inc что сломалось` или отвечает командой `/inc` на проблемное сообщение. Бот присылает отчёт тебе в Telegram, а сообщение, на которое ответили, пересылает следом. От одного пользователя принимается не больше одного инцидента в минуту.

Отчёты можно получать в отдельный канал (или лично от бота).

**В канал:**
1. Создай канал (можно приватный).
2. Добавь бота в администраторы канала с правом **Публикация сообщений**.
3. Напиши в канале `/id`. Бот ответит id канала вида `-100…`, после этого оба сообщения можно удалить.
4. На Render: сервис → **Environment** → **Add Environment Variable**, `ADMIN_CHAT_ID` = этот id → **Save**.

**Лично:** напиши боту `/id` в личке и укажи в `ADMIN_CHAT_ID` полученный id.

На другие посты в канале бот не реагирует.

Пока `ADMIN_CHAT_ID` не задан, `/inc` отвечает, что сообщить о проблеме сейчас нельзя.

## Консольный конвертер
```bash
.venv/bin/python tg_gif.py картинка.png anim.gif video.mp4
```
