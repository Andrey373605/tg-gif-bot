# tg-gif-bot

Бот для Telegram: кидаешь картинку, GIF, видео, стикер или ссылку, а он отвечает гифкой, которую можно сохранить в «Мои GIF». А на обычный текст отвечает Гойдик — свой пацан из чата, который всех подъёбывает (на Gemini).

Работает в личке и в групповых чатах. В группах бот реагирует только на отметку, ответы на сообщения Гойдика и команды:

| Что написать | Что делает |
|---|---|
| `@goydik_bot вопрос` | отвечает Гойдик; если отметить бота в ответ на сообщение, Гойдик учтёт и его |
| ответ (reply) на сообщение Гойдика | Гойдик продолжает разговор; ответы на гифки бота не считаются |
| `/gif` | ответь ей на картинку, видео, стикер или ссылку, или напиши `/gif ссылка` |
| `/goydik вопрос` (или `/g`) | спросить Гойдика; можно ответить `/goydik` на чужое сообщение |
| `/inc описание` | сообщить о проблеме с ботом |
| `/help` | что умеет бот |

В личке команды не нужны: картинки и ссылки превращаются в гифки, текст уходит Гойдику.

## 1. Создать бота
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя.
2. Скопируй токен вида `123456:ABC...`.

## 2. Проверить у себя (необязательно)
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
BOT_TOKEN=твой_токен .venv/bin/python bot.py
```
Без `WEBHOOK_URL` бот работает в режиме polling, публичный адрес не нужен.

## 3. Залить на Render (бесплатно)
1. Загрузи эту папку в новый репозиторий на GitHub (можно приватный).
2. На [render.com](https://render.com) → **New → Blueprint** → выбери репозиторий. Render подхватит `render.yaml`.
3. Когда спросит `BOT_TOKEN`, вставь токен → **Apply**.

Адрес для webhook бот берёт сам из `RENDER_EXTERNAL_URL`.

**Особенность бесплатного плана:** после ~15 минут без сообщений сервис засыпает. Первое сообщение его будит, ответ на него может идти до минуты. Дальше бот отвечает сразу.

## 4. Инциденты (/inc)
Пользователь пишет боту `/inc что сломалось` или отвечает командой `/inc` на проблемное сообщение. Бот присылает отчёт тебе в Telegram, а сообщение, на которое ответили, пересылает следом. От одного пользователя принимается не больше одного инцидента в минуту.

Отчёты можно получать в отдельный канал (или лично от бота).

**В канал:**
1. Создай канал (можно приватный).
2. Добавь бота в администраторы канала с правом **Публикация сообщений**.
3. Напиши в канале `/id`. Бот ответит id канала вида `-100…`, после этого оба сообщения можно удалить.
4. На Render: сервис → **Environment** → **Add Environment Variable**, `ADMIN_CHAT_ID` = этот id → **Save**.

**Лично:** напиши боту `/id` в личке и укажи в `ADMIN_CHAT_ID` полученный id.

На другие посты в канале бот не реагирует.

Пока `ADMIN_CHAT_ID` не задан, `/inc` отвечает, что сообщить о проблеме сейчас нельзя.

## 5. Гойдик (Gemini)
1. Получи ключ в [Google AI Studio](https://aistudio.google.com/apikey) → **Create API key**.
2. На Render: сервис → **Environment** → `GEMINI_API_KEY` = ключ → **Save and deploy**.
3. Необязательно: `GEMINI_MODEL`, если нужна другая модель (по умолчанию `gemini-3.8-flash`).
4. Необязательно: `GEMINI_FALLBACK_MODEL` — запасные модели через запятую, по порядку (по умолчанию `gemini-3.6-flash,gemini-3.5-flash-lite`). Если модель перегружена (503) или закончился её бесплатный лимит (429), бот сразу спрашивает следующую. Если модель долго молчит (20 секунд на варианты, 8 на выбор), бот спрашивает следующую параллельно и берёт тот ответ, что придёт первым. Перегруженная модель 5 минут не спрашивается первой, а модель с кончившимся дневным лимитом — час. Пустое значение выключает запасные модели. Лимиты считаются на проект Google, а не на ключ: сколько потрачено, видно в AI Studio на странице [Rate limit](https://aistudio.google.com/rate-limit), дневные лимиты обнуляются в полночь по тихоокеанскому времени.

**Как Гойдик отвечает.** Каждый ответ — два запроса к Gemini. Сначала основная модель придумывает 4 разных варианта (стёб, поржать, байка про себя, реакция в пару слов…). Потом первая запасная модель как придирчивый участник чата проверяет каждый вариант (притянутый факт из досье, повтор, длинно, мимо) и выбирает лучший. Поэтому ответ идёт на несколько секунд дольше, бот всё это время показывает «печатает…». Гойдику показывается досье только тех, о ком речь в сообщении, поэтому остальных он притянуть не может.

Характер Гойдика лежит в `prompt.txt`, досье на участников — в `people.txt` (формат описан в начале файла). Их можно править прямо на GitHub (открыть файл → ✏️ → **Commit changes**), Render сам перезапустит бота. Как бот упаковывает сообщения и что просит у моделей, описано в `goydik.py` (`DRAFT_TASK`, `JUDGE_PROMPT`), в текстовых файлах это повторять не нужно. На ловушки вроде «ответишь — значит лох» Гойдик молчит (в логе Render — `staying silent on a bait message`). Гойдик помнит последние 20 сообщений в каждом чате; после перезапуска сервера память обнуляется.

**Проверить правки до деплоя:** положи ключ в файл `.env` рядом с ботом (строка `GEMINI_API_KEY=...`, в git он не попадёт) и запусти `python -X utf8 try_goydik.py`. Скрипт отправит тестовые сообщения и покажет варианты, вердикты судьи и итоговый ответ. Тесты тратят тот же бесплатный лимит Gemini, что и бот.

Если Гойдик отвечает «упал под стол», загляни в логи Render: там будет ответ Gemini (например, неверное имя модели).

## 6. Добавить в групповой чат
1. Выключи режим приватности: [@BotFather](https://t.me/BotFather) → `/setprivacy` → выбери бота → **Disable**. Без этого Telegram присылает боту из группы только команды, и Гойдик не видит, о чём идёт разговор (а может не видеть и отметки).
2. В чате: **Добавить участника** → найди бота. Если бот уже был в группе до шага 1, удали его и добавь заново, иначе Telegram не применит настройку.
3. Права администратора боту не нужны.
4. Если в чате несколько ботов, пиши команды с именем: `/gif@goydik_bot`.

**Что бот делает с сообщениями группы.** Он держит в памяти последние 30 сообщений каждой группы (текст, подписи и пометки вроде «[фото]»), чтобы Гойдик понимал контекст, когда его отмечают. На диск и в логи они не пишутся и пропадают при перезапуске сервиса. Историю чата до своего появления бот не видит: у Telegram нет такой возможности для ботов. Реагирует бот по-прежнему только на отметку, ответы Гойдику и команды.

## Консольный конвертер
```bash
.venv/bin/python tg_gif.py картинка.png anim.gif video.mp4
```
